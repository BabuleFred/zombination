# Зомбинация — HTML5-ремейк

![HTML5 Canvas](https://img.shields.io/badge/HTML5-Canvas-e34f26)
![No dependencies](https://img.shields.io/badge/dependencies-0-success)
![License](https://img.shields.io/badge/license-MIT-blue)

Ремейк легендарной флеш-игры «Зомбинация» из ВКонтакте — на чистом HTML5 Canvas.

**Без Flash. Без фреймворков. Без единого внешнего файла-ассета: вся графика и весь звук
рисуются и синтезируются кодом прямо в браузере.**

> Фанатский проект. Оригинальная игра принадлежит её авторам; здесь воссоздан геймплей
> и визуальный стиль как упражнение на Canvas и WebAudio.

---

## Что это

Игра «стенка на стенку»: две базы, юниты идут по прямой и дерутся, ты тратишь монеты
на найм и защиту и пытаешься снести базу противника за 5 минут.

Реализовано:

- **Хаб «Арена»** — ночной готический склеп с совой, колоннами и атлантами. Кликабельны
  «Арена» (быстрый бой) и «Кампания».
- **Кампания** — карта-свиток с маршрутом, по 7 миссий на расу (зомби и фермеры),
  выбор расы за монеты, прогресс в `localStorage`.
- **Бой** — ферма с силосами против кладбища с болотом и часовней; цены юнитов из оригинала
  (36, 45, 180, 360, 405, 900, 1350…), лимит юнитов, механика «Ярость», «Банк»,
  ИИ противника, чат с репликами, очки и таймер.
- **Интро миссии** — ржавый баннер с приказом и наградой.

## Запуск

Игре не нужны сборка и зависимости — только браузер.

**Вариант 1.** Открыть `index.html` двойным кликом (Chrome / Edge / Firefox).

**Вариант 2.** Через локальный сервер (нужен только Python):

```bash
python -m http.server 8321
# открыть http://localhost:8321/
```

## Управление

- 🪙 Монеты начисляются со временем (быстрее с уровнем); за убийства — монеты, опыт, очки.
- 🃏 Юниты нанимаются карточками внизу экрана — они сами идут к базе врага (лимит 20).
- 🛡 Карточки «Защита» ставят ловушки и турели в 4 слота у базы.
- ⭐ Опыт повышает уровень и открывает новых юнитов.
- ⚔ «Ярость» заряжается от полученного урона: ×2 к атаке на 8 секунд.
- 🕓 Бой длится 5 минут: снести базу противника или победить по очкам.

## Как это устроено

```
index.html      канвас и HUD (хаб, карта, баннер миссии, панель карточек, чат)
css/style.css   ржаво-деревянные панели, камень, монеты
js/data.js      юниты и защита с ценами оригинала, кампании, уровни, фразы чата
js/sfx.js       звук: синтез через WebAudio, без файлов
js/draw.js      вся графика кодом — склеп, карта-свиток, ферма, кладбище, юниты
js/engine.js    бой, экономика, снаряды, ярость, ИИ противника, миссии
js/main.js      экранная система (хаб → карта → миссия → бой → результат) и HUD
```

Ключевая идея — **ноль внешних ассетов**. Персонажи, здания, снаряды, текстуры камня
и дерева, звуки выстрелов и ударов генерируются кодом. Это позволяет держать игру
в шести файлах и не тащить за собой мегабайты картинок.

## Стек

`HTML5 Canvas` · `JavaScript (ES6)` · `WebAudio API` · `localStorage`

## Идеи для развития

- Магазин, навыки, артефакты и архитектор из хаба (сейчас заглушки «скоро»).
- Прокачка юнитов, больше юнитов из оригинала (пчёлы, химикаты).
- Асинхронный PvP: сохранять расстановку защиты и атаковать чужие базы.
- Более богатая анимация.
